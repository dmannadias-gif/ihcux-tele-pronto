# 🏥 TelePronto — Protótipo UX/IHC

Projeto desenvolvido para a disciplina de Interação Humano Computador e UX.

O objetivo do aplicativo é facilitar o atendimento médico remoto, reduzindo filas em hospitais e oferecendo um fluxo simples, rápido e acessível para pacientes em situações de mal-estar.

# 📱 Sobre o Projeto

O TelePronto é um aplicativo de telemedicina criado para:

- Realizar triagem rápida de sintomas;
- Permitir consultas médicas por vídeo;
- Exibir receitas digitais;
- Configurar lembretes de medicamentos;
- Encontrar farmácias próximas.

O foco principal do projeto foi criar uma experiência simples, intuitiva e segura, principalmente para idosos e pessoas passando mal.

---

# 🧩 Funcionalidades do Protótipo

## ✅ Home / Dashboard
Tela inicial com acesso rápido às principais funções:
- Consulta imediata;
- Meus remédios;
- Receitas;
- Farmácias.

---

## ✅ Triagem Inteligente
Fluxo simples para o paciente informar sintomas de forma rápida e objetiva.

---

## ✅ Sala de Espera Virtual
Tela que informa:
- quantidade de pacientes na fila;
- tempo estimado;
- status da consulta.

---

## ✅ Videochamada Médica
Interface simples contendo:
- câmera;
- microfone;
- chat;
- botão de encerrar consulta.

---

## ✅ Receita Digital
Tela para:
- visualizar medicamentos;
- acessar QR Code;
- configurar lembretes;
- localizar farmácias próximas.

# ♿ Análise de Acessibilidade

O projeto foi pensado para usuários que podem estar com:
- visão turva;
- ansiedade;
- dificuldade motora;
- mãos trêmulas;
- dificuldade de concentração.

Para isso utilizamos:

- fontes grandes;
- botões amplos;
- poucos elementos por tela;
- linguagem simples;
- alto contraste;
- navegação intuitiva;
- mensagens claras de sistema.

As ações principais possuem maior destaque visual para reduzir erros durante o uso.

---

# 🚨 Fluxo Crítico

Fluxo utilizado para iniciar uma consulta de urgência:

1. Usuário acessa a Home;
2. Seleciona “Consulta Agora”;
3. Realiza a triagem rápida;
4. Entra na fila virtual;
5. Aguarda o médico;
6. Inicia a videochamada;
7. Recebe receita digital após o atendimento.

O fluxo foi desenhado para exigir o menor número possível de etapas.

---

# 🛡 Prevenção de Erros

Para evitar ações acidentais durante a consulta, foram implementadas soluções de segurança na interface:

- confirmação ao encerrar consulta;
- botão de emergência sempre visível;
- mensagens de status;
- hierarquia visual clara;
- botões críticos separados;
- feedback visual em ações importantes.

Isso reduz o risco de encerramentos acidentais e falhas de navegação.

---

# 🎨 Decisões de UX

Durante o desenvolvimento do protótipo, priorizamos:

- simplicidade;
- legibilidade;
- clareza;
- redução de carga cognitiva;
- facilidade para idosos;
- acessibilidade em situações de emergência.

O design evita excesso de informações e elementos desnecessários.
